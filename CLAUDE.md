# DES112 Project

This is a student project for DES112 at UC Davis.

- The published website lives in `/site`. Everything in that folder is deployed to GitHub Pages on every push to `main`.
- Keep the site static: HTML, CSS, and JavaScript only, with no build step.
- A live preview (`live-server`) runs on port 8080 while the codespace is open and reloads on save. Its log is at `/tmp/live-server.log`. If it isn't running, start it with `nohup live-server site --port=8080 --no-browser --quiet > /tmp/live-server.log 2>&1 &`.
- The student is learning. Explain what you change and why, in plain language, and prefer small steps they can follow.
- Don't complete the whole assignment for them. Help them build, debug, and understand their own work.
- Never add personal information (addresses, phone numbers, student IDs) to the site; it is public.
